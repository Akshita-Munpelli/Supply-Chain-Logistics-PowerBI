# Supply Chain & Logistics Analytics – Power BI

## Project Objective
The main objective of this project is to demonstrate how **Power BI can transform business data into interactive dashboards and meaningful insights** that support data analysis and business decision-making.

## Project Highlights
* Interactive and user-friendly Power BI dashboards
* KPI-based business performance monitoring
* Sales and profit analysis
* Inventory and product performance analysis
* Customer behavior analysis
* Supplier and warehouse performance analysis
* Shipment and logistics analysis
* Interactive slicers and filters for detailed exploration

##  Tools Used
* Power BI
* Power Query
* Excel
* Data Modeling
* DAX

## Dataset Used
- <a href="https://github.com/Akshita-Munpelli/Supply-Chain-Logistics-PowerBI/blob/main/FINAL_Supply_Chain_Logistics_COMPLETE.xlsx"> Dataset</a>

## Key KPIs
The dashboards track important business metrics such as:
* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Total Customers
* Total Suppliers

## Interactive Features
The dashboards include interactive filters and slicers for:
* Year
* Region
* Category
* Customer Type
* Warehouse
* Customer
